# Criterio de terminología anatómica en español

Este atlas conserva sin cambios los identificadores de **BodyParts3D/FMA** y añade una capa de presentación en español.

## Jerarquía terminológica

1. **Terminologia Anatomica 2 (TA2), FIPAT/IFAA**: referencia principal para la identidad y nomenclatura anatómica internacional.
2. **TA2Viewer (Open Anatomy + FIPAT)**: se usa para contrastar términos oficiales, sinónimos y términos relacionados, además de sus cruces con FMA.
3. **Diccionario Panhispánico de Términos Médicos (DPTM), RANME/ALANAM**: referencia para la forma médica en español, variantes panhispánicas y equivalentes ingleses.
4. Fuentes anatómicas médicas revisadas se usan para documentar variantes tradicionales o epónimos cuando ayudan al aprendizaje y a la búsqueda.

## Regla del atlas

- `name`: término preferido mostrado al estudiante.
- `nombreOriginal`: nombre fuente en inglés de BodyParts3D.
- `sinonimos`: variantes válidas, tradicionales, clínicas o epónimos útiles para búsqueda.
- `notaTerminologica`: advertencia cuando dos términos suelen confundirse o cuando el término tradicional difiere del preferido.
- Los IDs FMA/FJ, claves internas, binarios y rutas **no se traducen**.

## Ejemplos revisados

| Término preferido | Sinónimos / variantes de búsqueda | Observación |
|---|---|---|
| **Ulna** | cúbito | TA2 emplea *ulna* para el hueso; “cúbito” sigue siendo muy usado en español. |
| **Fíbula** | peroné | Ambas formas identifican el mismo hueso. |
| **Talus** | astrágalo | *Talus* corresponde a la nomenclatura internacional; “astrágalo” es tradicional en español. |
| **Rótula** | patela | Dos denominaciones para el mismo hueso; el atlas mantiene “rótula” como forma española principal. |
| **Escápula** | omóplato | “Escápula” es la denominación anatómica moderna; “omóplato” permanece como sinónimo. |
| **Tuba auditiva** | tuba faringotimpánica; trompa de Eustaquio | El epónimo se conserva para búsqueda, no como término preferido. |
| **Tuba uterina** | trompa uterina; trompa de Falopio | El epónimo se conserva como variante tradicional. |
| **Conducto colédoco** | colédoco; conducto biliar común | Variantes médicas de uso extendido. |
| **Conducto deferente** | vas deferens; vaso deferente; ducto deferente; canal deferente | “Conducto deferente” es la etiqueta principal del atlas. |
| **Hipófisis** | glándula pituitaria | “Hipófisis” se prefiere en español anatómico. |
| **Glándula suprarrenal** | glándula adrenal | Ambas formas son válidas en uso médico. |
| **Círculo arterial cerebral** | polígono de Willis; círculo de Willis | El epónimo queda como sinónimo. |
| **Tendón calcáneo** | tendón de Aquiles | Se prefiere la forma descriptiva; el epónimo sigue siendo clínicamente muy usado. |
| **Ángulo esternal** | ángulo de Louis; ángulo del esternón | El epónimo se conserva como variante. |
| **Encéfalo** | cerebro (uso general) | No son equivalentes estrictos: el cerebro es una parte del encéfalo. |

## Objetivo para estudio y examen

El buscador debe aceptar tanto la nomenclatura preferida como la forma que un profesor, libro o pregunta de examen pueda emplear. Por ello, una búsqueda de “cúbito”, “ulna”, “peroné”, “fíbula”, “trompa de Eustaquio”, “tuba auditiva”, “polígono de Willis” o “círculo arterial cerebral” debe conducir a la misma estructura correspondiente cuando exista en BodyParts3D.
